# PhotoFileForge

**PhotoFileForge** is a modern macOS desktop application for working with large local collections of photos, videos, and other files.

The project combines the workflow of a professional two-pane file manager with fast media browsing and batch file processing.

The primary goal is to make working with large filesystem-based photo and video libraries fast, convenient, and efficient.

> 🚧 **Early Development**
>
> PhotoFileForge is currently in the early development stage. The architecture, UI, and feature set are actively evolving.

---

## ✨ Concept

PhotoFileForge is designed as a combination of:

- a professional **two-pane file manager** inspired by Total Commander;
- a fast **photo and media viewer** inspired by FastStone Image Viewer;
- a **batch processing workspace** for renaming and editing large groups of files;
- a future **timeline view** for browsing media chronologically.

Unlike applications such as Apple Photos or Google Photos, PhotoFileForge is designed around the **normal filesystem**.

Your files remain in their existing folders and are not locked into a proprietary library structure.

---

# 🏗️ Technology

The project is being developed using:

- **C#**
- **.NET**
- **Avalonia UI**
- **MVVM**
- **JetBrains Rider**
- **Git**

The application is primarily targeting:

- **macOS**

The architecture is intended to keep the core functionality independent from the UI wherever practical.
